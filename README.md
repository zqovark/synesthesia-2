# Synesthesia 2

Instrumento audiovisual local: imagens, áudio, macros e gamepad. Identidade cósmica e sublime bíblico. Projeto independente do Synesthesia original.

Em desenvolvimento incremental. Veja [a arquitetura](docs/ARCHITECTURE.md) e os contratos do núcleo em `src/core/instrument.js`.

Node 22 ou superior. `npm test` executa os testes sem instalar dependências.
